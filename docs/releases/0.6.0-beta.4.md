# Nous Translator 0.6.0-beta.4

商店发布准备：记录已确认注册的 Bundle ID，补上实际上传前会卡住的包装项。Direct / GitHub 划词路径保持默认。

应用版本 0.6.0，build 10。商店版与 Direct 版共用该版本号，由 `NousDistribution` 区分。

- App Store Connect 已注册 `com.nous.translator`（资源 id `536KMKRF6V`）。**仍无 App record**，本仓库不创建该记录。
- 商店版 Keychain 使用 data-protection keychain；Direct 查找方式不变。
- `PrivacyInfo.xcprivacy` 声明 UserDefaults 原因 `CA92.1`。
- 商店应用 entitlements 增加 `com.apple.security.cs.allow-jit`（供继承沙盒的 llama-server / Metal；实机未验证）。
- Distribution 构建必须嵌入 Mac App Store provisioning profile；`scripts/prepare-appstore-upload.sh` 在本机打 PKG，**不会上传**。
- Linux 静态检查 workflow：`.github/workflows/static-checks.yml`。

本版**没有** Developer ID 公证，也**没有**上传 App Store Connect。Pico 许可仍是声明缺失。Mac 上的沙盒、Metal、Services、Apple Distribution 签名未在本环境执行。
