# Nous Translator 0.7.0-beta.2

优化翻译浮窗左上角目标语言切换入口样式：去掉箭头图标，改为直接显示语言名的 36pt 透明液态玻璃胶囊按钮，与右侧 36×36 圆形关闭按钮保持等高同曲率对称；点击仍弹出原有的语言切换菜单（含反转方向与全部 16 种语言）。应用版本 `0.7.0`，build `12`。

## 下载与升级

Apple Silicon（arm64）预览版。提供 DMG、ZIP、`release.json` 和 `SHA256SUMS.txt`。

- 已安装 `0.7.0-beta.1` 的用户可通过菜单栏 **检查更新…** 或 **Settings → General → Software Update** 直接一键下载、校验并自动重启升级。
- 此版本为 **ad-hoc 签名，尚无 Developer ID 签名和 Apple 公证**。首次手动打开如被 macOS 阻止，确认来自官方 Release 后按 [Apple 官方指引](https://support.apple.com/en-us/102445) 在「系统设置 → 隐私与安全性」点击「仍要打开」。最低编译目标为 macOS 14.0，目前实机验证系统为 macOS 27.3；Intel Mac 不受支持。

## 验证范围

- **本机已验证（Apple Silicon / macOS 27.3）**：全量 11 组离线回归测试（`scripts/test.sh`，含真实 Apple Vision 精准/快速 OCR 与更新器测试）、正式优化构建、DMG/ZIP 打包与签名回验（`package-release.py` + `verify-release.py`）。
- **尚未实机/在线验收**：macOS 14–26 其他系统版本、真实付费在线模型接口，以及 WindowServer 实时液态玻璃渲染下的点击交互验收。
