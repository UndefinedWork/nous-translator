# Nous Translator 0.5.0-beta.1

首个公开分发预览版 · 应用版本 0.5.0，build 6。

## 下载与安装

面向 **Apple Silicon Mac（arm64）**，不提供 Intel 版本。应用和本地运行器以 **macOS 14.0** 为最低编译目标；目前仅在 **macOS 27.3** 实机验证，其他系统版本尚未实机验证。

在本 Release 的 Assets 下载 `Nous-Translator-0.5.0-beta.1-macOS-arm64.dmg`，打开后把 Nous Translator 拖入 Applications，再从应用程序启动。它是菜单栏应用，入口在屏幕顶部翻译图标中。另提供 ZIP、构建清单 `release.json` 及 `SHA256SUMS.txt`。

**此预览版使用 ad-hoc 签名，尚未使用 Developer ID 签名，也未通过 Apple 公证。** 如果首次启动被阻止，请先确认文件来自 [官方 Release](https://github.com/UndefinedWork/nous-translator/releases/tag/v0.5.0-beta.1)。尝试打开后，进入“系统设置 → 隐私与安全性 → 仍要打开（Open Anyway）”，按提示确认，详见 [Apple 官方说明](https://support.apple.com/en-us/102445)。受管理的 Mac 可能不允许此操作；不要关闭 Gatekeeper 或通过终端移除隔离属性。

## 本版变化

- **首次使用可在应用内完成设置。** 缺少本地翻译模型时自动打开 Models，本地模型区域优先展示。Index-Translate 下载提供进度、取消、重试和重新下载修复；失败或取消时保留原模型。普通用户无需运行源码脚本。
- **改进 Nous Browser / Chromium 划词读取。** 提前准备网页辅助功能，兼容延迟返回的选区、部分非标准光标和选区位置，并取消过时的读取结果。
- **修复剪贴板兜底的取消恢复。** 能确认是本次复制结果时，取消读取仍会恢复原剪贴板；后续用户复制或归属不明的写入会保留，避免旧任务覆盖新内容。
- **翻译与通用对话分别配置。** 默认在本机翻译；可选 OpenAI、DeepSeek 或自定义兼容 API。通用对话需要独立的通用模型配置，API Key 保存在 macOS Keychain。
- **运行器随包提供。** 从固定 llama.cpp 源码构建 macOS 14.0 arm64 静态运行器，包含所需组件和 Metal 支持，移除对构建机器 Homebrew 运行库的依赖。
- **建立可核对的发布产物。** DMG 和 ZIP 对应同一源码提交，附构建清单、SHA-256 校验值、隐私说明和第三方许可文本。

## 第一次翻译

1. 打开 Settings → Models，在 On This Mac 中下载约 **1.3 GB** 的 Index-Translate-2B Q4_K_M，或选择已有的兼容 GGUF。模型权重不在安装包中；下载需要访问 Hugging Face 及其下载服务，完成后本地翻译可离线使用。
2. 在 Settings → Permissions 打开系统辅助功能页面，由你打开 Nous Translator 的允许开关。
3. 选中文字并点击翻译入口；也可以复制文字后选择菜单中的 Translate Clipboard，该入口不需要辅助功能权限。

选择在线模型后，相应文字及必要上下文会发送给所选服务。Test Connection 会发送简短测试请求，可能产生费用。本地模型失败不会自动切换到在线服务。通用对话可另选本地 GGUF 或在线模型，详细配置见 [使用说明](https://github.com/UndefinedWork/nous-translator#模型与对话)。

## 已知限制与验证范围

自动化回归覆盖划词规则、延迟读取、剪贴板取消/恢复及后续写入、输入框、服务商请求与流式响应、原生设置和首次模型下载。本地运行器已在独立端口完成中英双向真实推理检查。下载回归使用本机 HTTP 服务；网络条件仍会影响真实 Hugging Face 下载。部分本机选区验证不等于所有浏览器与应用的完整端到端验收。

当前不提供粘贴网页 URL 后自动提取整页正文、翻译及总结的功能。在线服务和用户自选通用模型的连通性与回答质量取决于各自配置。此版也尚未完成 macOS 14 至其他系统版本的实机兼容性验证。

从旧版本升级后，可能需要重新打开辅助功能允许开关。本项目的本机更新脚本会仅重置 Nous Translator 的辅助功能授权并打开系统页面，允许开关仍由用户操作；模型、历史、偏好和 API Key 会保留。
