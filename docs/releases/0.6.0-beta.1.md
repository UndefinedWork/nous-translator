# Nous Translator 0.6.0-beta.1

可选图片识别模型、自定义双向语言与翻译等待优化。应用版本 0.6.0，build 7。

## 下载

Apple Silicon（arm64）预览版。下载本页 Assets 中的 DMG，拖入 Applications；也提供 ZIP、release.json 和 SHA256SUMS.txt。

此版本为 **ad-hoc 签名，尚无 Developer ID 签名和 Apple 公证**。首次打开如被阻止，确认来自本官方 Release 后，按 [Apple 官方指引](https://support.apple.com/en-us/102445) 在“系统设置 → 隐私与安全性”选择“仍要打开”。不要关闭系统安全检查。应用及运行器的最低编译目标为 macOS 14；目前实机验证系统为 macOS 27.3，其他版本尚未实机验收。Intel Mac 不受支持。

## 本版变化

- **图片识别独立选模型**：新增 Settings → Images。默认 Apple Vision 本机文字识别，可切换 OpenAI 或支持图片的 Custom API，单独填写图片模型 ID。仅图片发送会直接显示识别文字，不要求对话模型；附带问题时再交给选定的对话模型处理。
- **可配置双向语言**：General 中选择语言 A、B，以及自动双向或固定方向。提供简繁中文、英语、日语、韩语等 16 种选项，浮窗显示本次源语言 → 目标。第三语言或无法判断的短词在自动模式下译向主语言 A；实际语言能力取决于模型。
- **在线翻译快速模式**：默认对已确认支持的 OpenAI 模型降低翻译请求的推理强度。保留用户选定的模型，不改变普通对话，也不启用额外付费的优先档位。General 中可恢复 Model default；未知模型和自定义服务不强加不支持的参数。
- **本地模型提前准备**：只在选择本机翻译、模型已下载且允许预热时加载翻译模型。闲置五分钟或内存紧张时释放，可在 General 关闭。修复取消启动、停止后立即重试、长流输出期间资源释放等竞态。
- **等待状态更清楚**：区分“加载本地模型”和“等待模型输出”，收到首段文字后直接显示译文。图片识别在后台处理，支持取消、尺寸限制及有限内存缓存。

## 数据与使用

在线图片识别会向所选服务发送缩放、重新编码后的图片，可能收费；默认 Apple Vision 不上传图片。图片识别和对话可以使用不同服务。PDF、文本附件仍在本机提取；没有自动换到其他在线服务的兜底。保存或删除同一提供方和地址的 Key 会影响使用该 Key 的其他功能。

本地 Index-Translate 权重约 1.3 GB，首次使用需单独下载，更新应用不会删除模型、历史、偏好或 Keychain。升级后可能需要重新打开辅助功能允许开关；本机更新工具仅重置 Nous Translator 自己的授权，不能自动授予权限。

## 验证范围

回归覆盖语言方向和配置迁移、选区读取、输入框、服务商请求、快速模式兼容参数、模型下载、本地模型启动/取消/闲置生命周期、图片请求构造/取消/缓存/异常，以及无需对话模型的附件识别。使用本机图片验证 Apple Vision；在线图片请求使用测试替身验证，没有调用真实收费 API。

另外，真实应用启动验证中观察到 Apple Vision 首次设备模型编译约需 20 秒；这发生在后台，首次或缓存未命中的识别可能较慢，后续速度取决于图片和系统缓存。

本机 M2 的本地 Index-Translate 基准中，在相同系统缓存条件下，未预热请求首字约 0.68 秒，预热完成后约 0.09 秒；第一次模型加载仍可能需要数秒。该数据只适用于本地模型，不代表在线模型速度。在线快速模式已验证请求参数，尚未使用真实付费账号做速度或识别质量对比。OpenAI 参数依据 [GPT-6.1 Terra 说明](https://developers.openai.com/api/docs/models/gpt-6.1-terra) 与 [模型兼容文档](https://developers.openai.com/api/docs/guides/latest-model)。
