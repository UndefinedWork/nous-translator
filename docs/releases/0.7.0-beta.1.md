# Nous Translator 0.7.0-beta.1

应用内 GitHub Release 自动检查更新与一键升级重启、全局快捷键、快捷输入翻译、截图区域 OCR 直译、浮窗体验全面升级，以及本地运行器与可靠性深度优化。应用版本 `0.7.0`，build `11`。

## 下载

Apple Silicon（arm64）预览版。提供 DMG、ZIP、`release.json` 和 `SHA256SUMS.txt`。

此版本为 **ad-hoc 签名，尚无 Developer ID 签名和 Apple 公证**。首次打开如被 macOS 阻止，请确认文件来自 [官方 Release](https://github.com/UndefinedWork/nous-translator/releases) 后，按 [Apple 官方指引](https://support.apple.com/en-us/102445) 在「系统设置 → 隐私与安全性」点击「仍要打开」。不要关闭 Gatekeeper 或手动移除隔离属性。最低编译目标为 macOS 14.0，目前仅在 macOS 27.3 实机验证；Intel Mac 不受支持。

## 本版变化

### 应用内更新（GitHub Releases）
- **自动检测与轻量提示**：启动后低频检查 `UndefinedWork/nous-translator` 的 GitHub Releases（支持 ETag / HTTP 304，可在 **Settings → General → Software Update** 开关自动检查与预览版通道）。发现新版本时，菜单栏图标显示蓝色提示圆点、菜单顶部置顶更新入口，并弹出轻量非抢焦点提示气泡。
- **一键下载、校验并自动重启**：在设置页可查看更新说明、下载进度并一键安装。下载仅允许官方 GitHub HTTPS 域，安装前核验 `SHA256SUMS.txt` / `release.json` 与 `codesign` 签名，以原子方式替换当前应用（失败自动回滚）并自动重启。模型、历史、偏好与 Keychain 密钥均保留；ad-hoc 预览版替换后仅重置 `com.nous.translator` 的辅助功能授权并打开系统设置页供用户重新允许。

### 划词浮窗与交互体验
- **目标语言快切与自适应缩放**：浮窗头部新增轻量目标语言切换菜单（一键反转或切换 16 种目标语言并重译）；短词采用紧凑初始高度，长译文/追问自动展开，并支持右下角拖拽自由调整大小；补齐 macOS 14 浮窗拖拽支持。
- **快捷控制与语音朗读**：内置系统离线语音朗读（`AVSpeechSynthesizer`，覆盖 16 种语言）、流式生成停止按钮、快捷键重译（`⌘R`）与复制译文（`⌘⇧C` / 非选区 `⌘C`）。
- **全局快捷键、快捷输入与截图 OCR 翻译**：新增无需辅助功能权限的 Carbon 全局快捷键（默认 `⌃⌥T` 翻译剪贴板、`⌃⌥N` 快捷输入翻译、`⌃⌥S` 截图区域 OCR 直译，可在 Settings → General 自定义），菜单栏同步提供对应入口；Apple Vision 首次编译超过 3 秒时显示友好准备提示。
- **设置、模型下载与历史升级**：Models / Images 页显示 Keychain 保存状态与未保存提醒，Images 页新增 **Test Connection**；本地模型下载支持断点续传（Resume）、镜像源（Hugging Face / HF-Mirror / 自定义 HTTPS）与 SHA-256 校验；历史记录支持关键词搜索、单条删除、复制原文、语言方向与来源应用元数据，以及一键在浮窗重新打开；新增中/英界面语言切换。

### 翻译质量、可靠性与性能
- **生命周期与崩溃韧性**：关闭翻译浮窗立即取消进行中的追问/OCR 任务并释放内存及临时 `Attachments/` 副本，应用启动与退出自动清理孤儿附件；本地 `llama-server` 改为每次启动动态分配回环端口、记录 PID 并按可执行路径核验清理崩溃残留孤儿进程、闲置停止增加异步 `SIGKILL` 兜底、取消唯一冷启动等待者时立即中止加载。
- **提示词与本地对话解耦**：在线模型翻译改用结构化 `system` + `<text app="...">` 提示词并传递来源应用语域；固定翻译方向不再注入可能误判的源语言；优化短英文词（如 `API`、`cache`）在拉丁/非拉丁语言对下的识别；本地对话模型使用独立别名、上下文（16384）与温度（0.7），不再被翻译专用参数绑定；在线 HTTP / SSE 报错透出经脱敏的服务端诊断信息。
- **性能与功耗优化**：流式输出绕过 `MessageTextCache` 防止驱逐已完成消息缓存；剪贴板 Copy 兜底增加 8 MB 快照预算、避开文件延迟承诺，并在恢复时写入 `TransientType` / `AutoGeneratedType` 标记；macOS 27.3+ 移除 1 秒权限轮询 Timer，旧系统改用事件驱动通知；粘贴图片去重落盘并异步解码缩略图；修复多显示器剪贴板浮窗定位。
