# Nous Translator 0.6.0-beta.2

移除翻译浮窗顶部多余的语言方向文字，恢复简洁的标题区。语言对和翻译方向仍可在 Settings → General 中设置。

本版只调整这处显示，不改变翻译、图片识别或模型配置。应用版本 0.6.0，build 8。

Apple Silicon 预览版，提供 DMG、ZIP 与校验文件；尚无 Developer ID 签名和 Apple 公证。首次打开说明见 [README](https://github.com/UndefinedWork/nous-translator#下载与安装)。最低编译目标 macOS 14，当前实机验证系统为 macOS 27.3。

已验证应用构建、语言方向回归及安装包完整性。源码和安装包对应同一提交。升级保留模型、历史和密钥；本机更新脚本会仅重置 Nous Translator 的辅助功能授权，允许开关仍需用户操作。
