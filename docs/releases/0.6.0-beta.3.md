# Nous Translator 0.6.0-beta.3

移除菜单栏重复的 “Enable Selection Translation…” 项。在 **Settings → Permissions** 查看划词权限，或打开 macOS 的辅助功能设置。

使用项目更新工具替换本机版本时，工具会重置 Nous Translator 的辅助功能权限，再由安装目录里的新版向 macOS 请求授权。即使本地模型还没配置，也能在这一步重新授权。较早的 macOS 在「隐私与安全性 → 辅助功能」中授权。macOS 27.3 请在 **System & App Protection Override** 点 **＋** 选择 Nous Translator，再点 **Choose Apps**，选择需要划词的应用（如 Nous Browser）。[Apple 操作说明](https://support.apple.com/en-us/149699)

在 macOS 27.3 上主动划词时，应用会针对当前应用检查可访问的选区，以支持按应用授权。

更新工具会临时备份旧应用，确认新版启动、权限页面已打开后再删除本次备份，避免累积可启动的旧版本。

Apple Silicon 预览版，build 10。提供 DMG、ZIP 和校验文件，采用 ad-hoc 签名，尚未通过 Apple 公证。验证范围为 macOS 27.3 上的本机安装、自动化回归与安装包检查。macOS 14.0 为最低编译目标，其他系统版本、用户授权后的真实浏览器划词和在线模型调用不在本次验收范围内。
