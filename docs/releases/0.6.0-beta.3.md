# Nous Translator 0.6.0-beta.3

增加 Mac App Store 编译通道：商店版用剪贴板、粘贴窗口和系统服务提供原文，不编译辅助功能划词。Direct / GitHub 安装包仍保留完整选区翻译。

应用版本 0.6.0，build 9。商店版与 Direct 版共用该版本号，由 `NousDistribution` 区分。

本版**没有** Developer ID 公证，也**没有**上传 App Store Connect。Pico 基准提交缺少 LICENSE 文件属于声明缺失，不是已证明无权利；在书面授权之前不能当作已可上架。Mac 上的沙盒、Metal、系统服务与 Apple Distribution 签名尚未在本环境验证。

Direct 预览包仍按 [docs/RELEASING.md](../RELEASING.md) 打 DMG。商店布局构建见 [docs/APP_STORE.md](../APP_STORE.md)。
